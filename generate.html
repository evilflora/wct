1. README

If you don't know what you're doing, PLEASE do nothing.

Download the newest version from GitHub (so you need to have an internet connection). If you're afraid of doing something wrong, do nothing.

You can update data yourself by following these steps:

    • a. Click Fetch and generate in section 2.: most JSON file of WFCD/warframe-items - data/json is downloaded in your browser and merged (excluded files are skipped)

      b. Result will be shown in 3., if no error is indicated, you can now copy the whole result and replace the content of the file js/data/data_generated.js

    • Data is community-maintained by WFCD, not an official Digital Extremes export.

    2. Generate

    3. Result (paste into js/data/data_generated.js)
